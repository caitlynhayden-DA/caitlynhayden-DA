# 💖 Featured Projects

## ☕ Caitlyn's Coffee Warehouse | Power BI

My full **end-to-end business intelligence project** built around a fictional coffee warehouse operation.

What started with raw Excel data became a multi-page Power BI reporting solution covering revenue, costs, profitability, invoices, customers, products, and sales performance.

### ✨ What I did:
- Cleaned and transformed data with **Power Query**
- Built a relational **data model**
- Developed custom **DAX measures and KPIs**
- Created revenue, expense, invoice, and customer analysis
- Built three interactive dashboard pages
- Tested filtering, relationships, measures, and refresh behavior
- Translated the finished analysis into actionable business insights

**Basically: raw data → clean data → model → measures → dashboards → business insights. 📈**

This one is especially close to my professional experience. 💗

After working directly in employee training and development, I identified a need for training documentation that was more **structured, consistent, measurable, and scalable**.

In my professional role, I developed training resources including progress reports, touchbase documentation, accountability tracking, how-to guides, quick-reference materials, and workflow documentation.

- Dynamic notes and alerts
- Readiness assessments
- Formula-driven cross-sheet reporting

This project is a great example of my favorite kind of work:

## ✈️ Interactive Travel Planning Dashboard | Excel

Proof that spreadsheets do **not** have to look like spreadsheets. 🎀

This project was intentionally much more design-heavy and gave me room to explore **dashboard architecture, UX/UI, visual hierarchy, automation, and interactive Excel design**.

I created a multi-sheet travel-planning system that brings all the moving pieces of a trip into one centralized, user-friendly experience.

### ✨ Features include:

- Budget & savings tracking
- Interactive packing progress
- Reservation management
- Multi-day itinerary
- Pre-trip checklist
- Automated dashboard cards
- Progress indicators
- Backend calculation tables
- Two-traveler planning
- A whole lot of pink 💕

Underneath the design is a formula-driven workbook that automatically updates dashboard metrics as the underlying planning data changes.

**Functional + intuitive + pretty = exactly my kind of dashboard.**
